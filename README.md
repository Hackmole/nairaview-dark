# Nairaview Dark

Nigerian Exchange (NGX) market information website — newly listed stocks, market news, stock performance and live charts.

Dark-theme redesign of [nairaview.com](https://nairaview.com): the deep-green/gold dark scheme is the default experience on every page (a light-mode toggle remains in the header). Data: 5 Oct 2026 close.
- Single-file static site (`index.html`), deployed on Cloudflare.
- Market data snapshot updated daily; live ticker via embedded no-key widget.

Informational only — not investment advice.
